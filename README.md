### Repositório destinado às atividades da disciplina Engenharia de Software III

#### - Strategy:
Exemplo do padrão Strategy e seu Anti-Pattern. O Pattern utiliza classes separadas para cada forma de pagamento, facilitando a manutenção e a adição de novos métodos. O Anti-Pattern utiliza estruturas condicionais (`if/else`), gerando maior acoplamento e dificultando futuras alterações.

#### - Observer:
Exemplo do padrão Observer e seu Anti-Pattern. O Pattern utiliza interfaces e uma lista de observadores para notificar seguidores de forma flexível. O Anti-Pattern realiza as notificações diretamente, criando forte dependência entre a página e os seguidores.
